#ชื่อชุดข้อสถานะจัดการ

สร้างชุดคำศัพท์

1 จับคู่Matching
2 สะกดSpelling
3 ฟัง-พูดListen & Repeat
4 เติมช่องว่างFill-in-blank

1️⃣ จับคู่คำศัพท์ (Master Data) 0

ℹ️ กรอกคำภาษาอังกฤษ (EN) และคำแปลภาษาไทย (TH) ให้ครบอย่างน้อย 10 คู่ — คู่คำเหล่านี้คือข้อมูลหลัก (Master) ที่ทุกโหมดอ้างอิง
ภาษาอังกฤษ ภาษาไทย

2️⃣ เลือกคำศัพท์สำหรับสะกด (Spelling) 0

ℹ️ เลือกคำศัพท์จากโหมดจับคู่ (Step 1) เพื่อเป็นแบบฝึกหัดสะกด — ผู้เรียนจะต้องสะกดคำศัพท์ให้ถูกตามคำแปลภาษาไทย
เลือก ภาษาอังกฤษ ภาษาไทย

3️⃣ เลือกคำศัพท์สำหรับฟังและพูดตาม (Listen & Repeat) 0

ℹ️ เลือกคำศัพท์จากโหมดจับคู่ (Step 1) สำหรับให้ผู้เรียนฟังเสียงและพูดตาม — ผู้เรียนสามารถข้ามด่านนี้ได้
เลือก ภาษาอังกฤษ ภาษาไทย

4️⃣ ประโยคตัวอย่าง (โหมดเติมช่องว่าง) 0

ℹ️ เลือกคำศัพท์จากโหมดจับคู่ที่จะเว้นช่องว่าง แล้วกรอกประโยคภาษาอังกฤษและคำแปล — ส่วนนี้ไม่ได้กำหนดคำศัพท์ใหม่ อ้างอิงจาก Master เท่านั้น
คำศัพท์ (EN) ประโยคภาษาอังกฤษ คำแปลประโยค
บันทึกเป็นแบบร่าง เผยแพร่ทันที
